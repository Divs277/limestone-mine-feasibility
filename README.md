# Techno-Economic Feasibility of an Open-Pit Limestone Mine

I'm a second-year mining engineering student. This project asks one question: would a ~1 Mtpa limestone quarry be a good investment, and what could make it fail?

I estimate how much material must be moved and how many trucks that needs, then build a discounted cash flow model in Python that gives NPV, IRR and payback. A sensitivity analysis shows which inputs matter most. All inputs are in `data/assumptions.csv`.

## Status
Work in progress. The model runs, and I am replacing the starting assumptions with values from public sources.

## What's in the repo
- `data/assumptions.csv`: every input with its unit and source (edit this, not the code)
- `src/model.py`: fleet sizing, cash flows, NPV, IRR, payback, sensitivity
- `outputs/`: charts generated by the model
- `memo/`: recommendation memo

## How to run
```
pip install -r requirements.txt
python src/model.py
```

## Method
1. Mine life = reserve / annual ore production
2. Revenue = ore tonnes x price; opex = mining (ore + waste) + processing + royalty + overhead
3. Tax on (EBITDA - straight-line depreciation); cash flow = EBITDA - tax
4. NPV at the chosen discount rate, IRR by bisection, payback from cumulative cash flow
5. Trucks needed = daily material moved / tonnes one truck can haul per day
6. Sensitivity: each input changed by -20% and +20%, ranked by effect on NPV

## Limitations
- Constant production and price; no ramp-up, inflation or working capital
- Royalty and taxes are simplified
- Costs are assumptions from public benchmarks, not a site-specific study
- No block model or pit optimisation (a possible next step)
